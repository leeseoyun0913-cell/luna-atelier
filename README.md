# LUNA Atelier

브라우저에서 플레이하는 피아노 리듬 게임입니다. 클래식, 재즈, K-pop 스타일 창작곡 등 14곡과 MIDI 가져오기, 자유 연주를 지원합니다.

## 플레이

- 곡을 선택하고 난이도와 연주 속도를 고른 뒤 시작합니다.
- 노트가 판정선에 닿으면 왼쪽부터 **D · F · J · K**를 누릅니다. 화면 터치도 가능합니다.
- 처음 소리가 나지 않으면 **소리 켜기** 또는 **소리 테스트**를 누르세요.
- **Space**는 일시정지, 자유 연주는 **A S D F G H J K / W E T Y U**입니다.
- 좋아요, 연주 기록, 가져온 MIDI는 각 방문자의 브라우저에 저장됩니다.

## GitHub Pages

`index.html`과 `.nojekyll`을 저장소의 `main` 브랜치 루트에 올립니다. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**를 선택하면 GitHub Pages가 배포합니다.

설치나 빌드가 필요 없는 정적 사이트이며, 외부 음원 서버나 별도의 계정 시스템을 사용하지 않습니다.

## 수록곡 안내

클래식은 테마를 발췌한 게임용 편곡입니다. Mr. C.C.는 사용자 제공 저해상도 악보의 9–13마디 오른손 테마를 반복하는 약 31초의 연습 편곡이며 원곡 전체가 아닙니다. 일부 판독 오차가 있을 수 있습니다. 다른 현대 장르의 수록곡은 LUNA 창작 연습곡입니다.
